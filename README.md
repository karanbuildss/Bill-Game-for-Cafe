# Bill Roulette

Bill Roulette is a frontend-only party game for cafes, friends, and small groups. Players add their names, choose a mini-game, and let the game decide who pays.

## Features

- Add, remove, and validate player names
- Player names are remembered on the same device using `localStorage`
- Sound on/off toggle
- Mobile-friendly layout
- Four mini-games:
  - Spin Wheel
  - Finger Chooser
  - Dice Roll
  - Plinko Board

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- HTML5 Canvas
- Web Audio API
- LocalStorage

## How To Run

Open the project with VS Code Live Server:

```text
fusion-version/index.html
```

No backend, database, npm install, or build step is required.

## Notes

Finger Chooser works best on mobile or touch-screen devices because it uses multi-touch input.
